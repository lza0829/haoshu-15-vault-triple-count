# 号枢

中文名：**号枢** · 前缀 `haoshu` · 端口 **6300 / 11300**

## 金库三方计数（按批勾稽）

全局唯一口径 **乙：三计数相等且批内勾稽可解释**——回执枢纽/链接/卫星三计数必须与
库内按批号标签可追溯的本批增量三计数相等；且本批每条新链接两端枢纽、每条新卫星父
都能在「本批新增 ∪ 装载前已有」中解释。任一不满足即 `valid=0`，对账与批成功标志
同一原子提交、同成败，失败闭回滚，回执不得维持成功。

- 行级 `批号` 标签 + `批次勾稽` 持久表，禁止全库总数冒充本批；老库幂等迁移。
- 装载全程单事务 `BEGIN IMMEDIATE` 持写锁，封账触发器禁止旁路插/删/改成功批标签行
  （卫星仅放行装载序闸内的同身份关版 1→0）。
- 只读接口：`GET /api/批勾稽`（列表）、`GET /api/批勾稽/{批号}`（批号、三计数、
  不可解释父子、valid、口径、说明）。
- 口径可区分性：三计数相等但混入父不可解脏链时，口径甲（仅计数相等）会放行，
  口径乙必须失败。

```bash
python3 -I tests/test_金库三方计数.py
# T0 迁移 / T1 正常批 / T2 脏链(乙必败) / T3 并发旁路 / T4 计数分叉 / T5 接口字段
# T6 成功批被篡改贯验报红 / T7 失败批失败闭证据正确
```
